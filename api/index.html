Free data API

Every score on Faultline is also available as plain JSON files: no key, no sign-up, updated weekly with the site. Fetch them from a browser, a spreadsheet, Python or anything else. Data as of 2026-11-25.

FileWhat's in it
api/v1/companies.jsonEvery scored company (7,698) with its latest scores (about 3 MB)
api/v1/c/<cik>.jsonOne company: every 10-K and 10-Q score since 2016, filing events, SEC accounting cases, what drives the latest score. Example: Apple (CIK 320193)
api/v1/receipts.jsonBankruptcies of the last 12 months and the last score before each
api/v1/meta.jsonData date and what each field means

Example (Python)

import requests
apple = requests.get("https://mahirzmansuri-hash.github.io/earnings-scanner/api/v1/c/320193.json").json()
print(apple["bankruptcy_percentile"], apple["history_10k"][-1])

Fields

  • cik: SEC Central Index Key (company id)
  • name: company name
  • ticker: main ticker, if any
  • industry: SEC industry (SIC) description
  • status: active or inactive (no filings for over a year: delisted, acquired or bankrupt)
  • filed: filing date of the 10-K behind the scores (the date the data became public)
  • period_end: fiscal period end of that 10-K
  • bankruptcy_risk: calibrated probability of a bankruptcy filing within 2 years (0-1)
  • bankruptcy_percentile: share of 10-Ks filed in the previous 365 days with a lower risk (0-1)
  • restatement_risk: calibrated probability of a restatement notice (8-K Item 4.02) within 2 years (0-1)
  • restatement_percentile: share of 10-Ks filed in the previous 365 days with a lower restatement risk (0-1)
  • altman_z: Altman Z-Score (1968); below 1.8 distress, above 3 safe
  • piotroski_f: Piotroski F-Score (0-9); higher is stronger
  • beneish_m: Beneish M-Score; above -1.78 flags possible earnings manipulation
  • latest_10q: latest 10-Q update: filing date, bankruptcy risk and percentile among 10-Qs of the previous 365 days

Point in time: each score uses only filings public on its date, from a model trained only on earlier outcomes. Companies are looked up by SEC CIK (find it on any company page). Banks and insurers are not scored. Research data, not investment advice; if you use it, please link back to Faultline.
